# Пробковая доска — сайт заметок (Python + Django + Bootstrap)

Учебный проект: заметки с авторизацией, закрепом, архивом и удалением.

## Запуск (без виртуального окружения)

```bash
cd notes_site
pip install -r requirements.txt
python manage.py migrate          # создаёт базу db.sqlite3
python manage.py runserver
```

Откройте http://127.0.0.1:8000, зарегистрируйтесь и войдите.

- Админка: `python manage.py createsuperuser`, затем http://127.0.0.1:8000/admin/
- Режим отладки (показывает ошибки подробно): `DEBUG=1 python manage.py runserver`
  (в Windows: `set DEBUG=1`, затем `python manage.py runserver`)
- Свой секретный ключ (иначе после перезапуска все выйдут из аккаунта):
  `SECRET_KEY=длинная-случайная-строка`

## Тесты

```bash
python manage.py test
```

8 тестов проверяют: вход обязателен, регистрация, слабый пароль не
принимается, добавление → закреп → архив → удаление, удалять через GET
нельзя, защита от XSS, нельзя удалить чужую заметку, защита от CSRF.

## Что умеет сайт

| Функция | Как работает |
|---|---|
| Регистрация / вход / выход | встроенная авторизация Django |
| Добавить заметку | заголовок, текст, цвет стикера |
| Закрепить | закреплённые всегда сверху и приколоты красной кнопкой |
| Архив | заметка уходит на страницу «Архив», её можно вернуть |
| Удалить | с подтверждением в браузере |

## Почему Django

В Django уже есть то, что нужно для безопасного сайта: пользователи и
вход, хэширование паролей, защита от CSRF, ORM (без ручного SQL),
админка. Не нужно писать это самому и ошибаться.

## Бэкенд — коротко

- **Модель** `Note` (`models.py`): владелец, заголовок, текст, цвет,
  `pinned`, `archived`, дата. Сортировка: закреплённые сверху, потом новые.
- **Представления** (`views.py`): каждое помечено `@login_required`,
  изменяющие — ещё `@require_POST`. Заметка ищется функцией
  `get_note` только среди заметок текущего пользователя.
- **Вход/выход** — готовые `LoginView` и `LogoutView`, регистрация —
  стандартная `UserCreationForm`.

## Фронтенд — как устроен

**Bootstrap 5** даёт основу: сетку (`row`, `col-lg-4`), меню (`navbar`),
кнопки (`btn`), поля (`form-control`), сообщения (`alert`).
Подключается с CDN в `base.html`; атрибут `integrity` — это хэш файла,
браузер не выполнит файл, если его подменили.

**Шаблоны Django.** `base.html` — общий каркас, остальные страницы
пишут `{% extends "base.html" %}` и заполняют блок `content`.
Стикер вынесен в `_note.html` и подключается через `{% include %}`.
В каждой форме есть `{% csrf_token %}`.

**Свой CSS (`style.css`)** — то, что отличает сайт от шаблонного Bootstrap:

- фон-пробка сделан двумя `radial-gradient` (точки разного цвета), без картинок;
- шапка — «деревянная рамка» через `linear-gradient`;
- каждый стикер слегка наклонён `transform: rotate(...)`; с помощью
  `:nth-child` наклон чередуется, поэтому доска выглядит «живой»;
- при наведении стикер выпрямляется и приподнимается (`scale` + тень);
- закреплённый стикер висит ровно, а сверху «воткнута» красная кнопка
  (`.pushpin` — круг с `radial-gradient`, похожий на объёмную булавку);
- в архиве стикеры «выцветают» (`filter: grayscale`);
- цвет стикера выбирается кружками — это обычные радиокнопки Bootstrap
  (`btn-check`), оформленные как цветные точки.

**JavaScript (`script.js`)** — совсем немного: окно подтверждения перед
удалением и счётчик символов. Обработчики вешаются через
`addEventListener`, а не `onclick=""`, потому что политика безопасности
(CSP) запрещает встроенные скрипты.

## Почему стоит выбрать этот сайт (уникальность)

Обычные заметки — это скучный список. Здесь заметки выглядят как
**настоящие бумажные стикеры на пробковой доске**: разноцветные, слегка
кривые, а важные — приколоты булавкой. Такую доску понятно с первого
взгляда: что приколото — важно, что в архиве — выцвело.

## Безопасность

- **Пароли** — хэш PBKDF2 (встроено в Django) + проверки: минимум 8
  символов, не слишком простой, не только цифры.
- **SQL-инъекции** — запросы через ORM, SQL руками не пишется.
- **XSS** — шаблоны Django экранируют вывод (`<script>` покажется как
  текст) + заголовок `Content-Security-Policy`.
- **CSRF** — `CsrfViewMiddleware` и `{% csrf_token %}` в каждой форме;
  все изменения (удалить, закрепить, архив, выход) только через POST.
- **Чужие заметки** — поиск всегда с `user=request.user`, на чужую
  заметку вернётся 404.
- **Сессия** — cookie `HttpOnly` и `SameSite=Lax`; при `HTTPS=1`
  включаются secure-куки, редирект на HTTPS и HSTS.
- **Заголовки** — `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`.
- **DEBUG выключен по умолчанию** — посторонние не увидят код при ошибке;
  `ALLOWED_HOSTS` ограничен.

## Развёртывание на сервере (Ubuntu)

На сервере (домен уже должен указывать на IP сервера):

```bash
wget https://raw.githubusercontent.com/kuzoVS/TaskReload/python/notes_site/deploy/deploy.sh
sudo bash deploy.sh ваш-домен.ru
```

Скрипт ставит nginx, скачивает код в `/opt/notes`, ставит зависимости
(без venv), создаёт секретный ключ в `/etc/notes.env`, запускает сайт
через gunicorn как сервис `notes` и получает HTTPS-сертификат.
Обновить сайт — запустить скрипт ещё раз. Логи: `journalctl -u notes`.
