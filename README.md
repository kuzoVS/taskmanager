# TaskReload — Пробковая доска

Сайт заметок на Python (Django + Bootstrap): регистрация и вход,
добавление, удаление, закреп и архив заметок.

Весь проект находится в папке [`notes_site/`](notes_site/) —
там же подробный README: запуск, тесты, устройство фронтенда и безопасность.

```bash
cd notes_site
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
